학회·행사 프로그램을 모바일에서 넘겨보는 슬라이드로 만드는 법

긴 세로 이미지 한 장으로 된 행사 프로그램, 휴대폰에서 보기 불편하셨죠? 좌우로 넘겨보는 슬라이드로 바꾸면 훨씬 보기 좋습니다. 설치나 회원가입 없이 무료로 만드는 방법을 정리했습니다.

왜 슬라이드 형태가 더 좋을까

학회나 세미나 프로그램은 보통 한 장의 긴 이미지나 PDF로 만들어집니다. 그런데 이걸 휴대폰으로 보면 글자가 너무 작아 계속 확대하고 스크롤해야 합니다. 참석자 입장에서 불편하죠.

프로그램을 섹션별로 나눠 좌우로 넘겨보는 슬라이드(캐러셀)로 만들면, 화면 하나에 한 부분씩 꽉 차게 보여 줄 수 있습니다. 손가락으로 넘기기만 하면 되니 직관적이고, 링크 하나로 공유할 수 있어 인쇄물도 필요 없습니다.

준비물

  • 프로그램 이미지 (한 장씩 나눠진 이미지면 가장 좋습니다)
  • 인터넷 브라우저 (크롬, 엣지, 사파리 등)
💡 프로그램이 긴 이미지 한 장이라면, 먼저 섹션별로(예: 표지, 1일차, 2일차) 잘라 두면 결과가 더 깔끔합니다. 캡처 도구나 이미지 편집 앱으로 부분 캡처하면 됩니다.

따라 하기

1. 이미지 업로드

캐러셀 메이커를 열고, 나눠 둔 프로그램 이미지를 끌어다 놓거나 클릭해서 한 번에 올립니다. 파일 이름순(01, 02, 03…)으로 자동 정렬되니, 파일 이름에 순서를 붙여 두면 편합니다.

2. 순서 정리

이미지를 드래그해 원하는 순서로 배치합니다. 표지 → 인사말 → 1일차 → 2일차 같은 흐름으로요. 잘못 넣은 이미지는 삭제하고, 실수했다면 Ctrl+Z로 되돌릴 수 있습니다.

3. 1일차·2일차로 나누기 (선택)

프로그램이 여러 날이라면 "그룹" 기능으로 날짜별로 나눠, 각각 별도의 슬라이드 파일로 만들 수 있습니다. 전체를 하나로 만들 수도 있고요.

4. 제목과 색상 설정

행사 이름을 제목으로 넣고, 행사 분위기에 맞는 배경색·강조색을 고릅니다. 학회라면 차분한 네이비에 골드 강조가 잘 어울립니다.

5. 다운로드

"전체 다운로드"를 누르면 HTML 파일 하나가 저장됩니다. 이 파일을 열면 바로 슬라이드가 작동합니다. 모든 이미지가 파일 안에 포함되어 있어, 인터넷 없이도 열립니다.

참석자에게 링크로 공유하기

다운로드한 HTML 파일을 그대로 카카오톡이나 이메일로 보내도 열립니다. 하지만 웹 링크(URL)로 공유하면 더 깔끔합니다. 무료 호스팅 서비스인 Netlify Drop(app.netlify.com/drop)에 파일을 올리면 인터넷 주소가 만들어지고, 그 링크를 안내문이나 단체 채팅방에 공유하면 됩니다.

참석자는 링크를 누르기만 하면 휴대폰에서 바로 프로그램을 넘겨볼 수 있습니다. 인쇄물 배포나 무거운 PDF 다운로드가 필요 없습니다.

자주 묻는 질문

이미지가 서버에 올라가나요?

아니요. 모든 작업은 사용자의 브라우저 안에서만 이루어집니다. 이미지가 외부로 전송되지 않으니 미공개 행사 자료도 안심하고 사용할 수 있습니다.

휴대폰에서도 만들 수 있나요?

네. 다만 여러 이미지를 올리고 순서를 정하는 작업은 PC가 더 편합니다. 만든 슬라이드를 보는 것은 휴대폰에서도 완벽하게 작동합니다.

나중에 수정할 수 있나요?

네. "기존 HTML 불러와서 편집" 기능으로 예전에 만든 파일을 다시 불러와 이미지나 색상을 바꿀 수 있습니다.

How to turn an event program into a swipeable mobile slideshow

Is your event program a single long vertical image that's painful to read on a phone? Turning it into a left/right swipeable slideshow makes it far nicer. Here's how to make one for free, with no install or sign-up.

Why a slideshow works better

Conference and seminar programs are usually made as one long image or PDF. But on a phone, the text is tiny and you have to keep zooming and scrolling. That's frustrating for attendees.

If you split the program into sections and make a left/right swipeable slideshow (carousel), each screen shows one part, filling the display. Swiping with a finger is intuitive, and you can share it with a single link — no printouts needed.

What you'll need

  • Your program images (ideally split into separate images)
  • A web browser (Chrome, Edge, Safari, etc.)
💡 If your program is one long image, cropping it into sections first (e.g. cover, Day 1, Day 2) gives a cleaner result. Use a screenshot tool or image editor to crop the parts.

Step by step

1. Upload images

Open Carousel Maker and drag in your split program images, or click to upload them all at once. They're auto-sorted by file name (01, 02, 03…), so numbering your files makes it easy.

2. Arrange the order

Drag images into the order you want — for example, cover → greeting → Day 1 → Day 2. Delete any wrong images, and press Ctrl+Z to undo a mistake.

3. Split into Day 1 / Day 2 (optional)

If your program spans several days, use the "Groups" feature to split by date and create a separate slideshow file for each. You can also keep everything as one.

4. Set the title and colors

Enter the event name as the title and pick background and accent colors that fit the mood. For an academic event, a calm navy with gold accents works well.

5. Download

Click "Download all" to save a single HTML file. Open it and the slideshow works right away. All images are embedded in the file, so it even opens offline.

Share a link with attendees

You can send the downloaded HTML file directly via messenger or email and it will open. But sharing a web link (URL) is cleaner. Upload the file to the free hosting service Netlify Drop (app.netlify.com/drop) to get an internet address, then share that link in your announcement or group chat.

Attendees just tap the link to flip through the program on their phone. No printouts, no heavy PDF downloads.

FAQ

Are the images uploaded to a server?

No. Everything happens in your browser. Images are never sent anywhere, so you can safely use unreleased event materials.

Can I make it on a phone?

Yes, though uploading several images and arranging the order is easier on a PC. Viewing the finished slideshow works perfectly on a phone.

Can I edit it later?

Yes. Use "Import HTML" to load a file you made before and change the images or colors.
