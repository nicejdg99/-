자주 묻는 질문FAQ
용량이 거의 안 줄어요.The size barely changed.▶
글자(텍스트) 위주의 PDF는 원래 용량이 작아서 더 줄어들 여지가 적어요. 이 도구는 스캔본이나 사진이 많은 PDF에서 효과가 큽니다. 이미 작은 PDF라면 원본을 그대로 쓰는 게 나아요.Text-only PDFs are already small, so there's little to compress. This tool shines on scanned or image-heavy PDFs. If your PDF is already small, it's better to keep the original.
압축하면 글자를 복사할 수 없게 되나요?Does the text become non-selectable?▶
네. 이 도구는 각 페이지를 이미지로 다시 만들어 용량을 줄이는 방식이라, 압축 후에는 글자 선택·복사가 안 됩니다. 글자 선택이 꼭 필요하면 원본을 보관해 두세요.Yes. This tool re-renders each page as an image to reduce size, so text can't be selected or copied afterward. Keep the original if you need selectable text.
제 PDF가 서버에 올라가나요?Is my PDF uploaded to a server?▶
아니요. 모든 압축은 브라우저 안에서만 이루어집니다. 파일이 인터넷 어디로도 전송되지 않으며, 페이지를 닫으면 즉시 사라져요.No. All compression happens in your browser. The file is never sent anywhere and disappears the moment you close the page.
압축이 너무 느려요.Compression is slow.▶
페이지가 많은 PDF는 시간이 걸릴 수 있어요. 진행 표시가 끝날 때까지 잠시 기다려 주세요. 아주 큰 PDF라면 먼저 PDF 편집기로 필요한 페이지만 남긴 뒤 압축하는 것도 방법이에요.PDFs with many pages can take a while. Please wait for the progress to finish. For very large PDFs, you can first keep only the pages you need with PDF Editor, then compress.
